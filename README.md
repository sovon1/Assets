# Assets

A personal collection of assets for use in various projects along my journey.

## 📁 Repository Structure

```
Assets/
├── images/          # Image assets
│   ├── photos/      # Personal photos and photography
│   ├── graphics/    # Design graphics and illustrations
│   └── screenshots/ # Screenshots and screen captures
│
├── documents/       # Document assets
│   ├── pdfs/        # PDF documents and references
│   ├── notes/       # Text notes and markdown files
│   └── references/  # Reference materials
│
├── fonts/           # Custom fonts and typography
│
├── icons/           # Icon assets
│   ├── svg/         # Scalable Vector Graphics
│   └── png/         # PNG format icons
│
├── media/           # Audio and video assets
│   ├── audio/       # Audio files and sound effects
│   └── video/       # Video files and clips
│
└── templates/       # Reusable templates
```

## 🎯 Purpose

This repository serves as a centralized location for organizing and versioning personal assets that can be referenced and reused across different projects.

## 📝 Usage

1. Navigate to the appropriate folder based on asset type
2. Each folder contains a README with specific guidelines
3. Add your assets maintaining the organized structure
